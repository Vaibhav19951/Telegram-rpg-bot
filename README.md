# RPG Telegram Bot

## Setup
1. Python 3.10+ install kare
2. Folder structure follow kare
3. `config.py` me TOKEN dal
4. `python -m pip install -r requirements.txt`
5. `python bot.py` run kare

## Commands
/profile        -> Show player profile
/inventory      -> Show inventory
/map            -> Show map locations
/dungeon        -> Enter dungeon
/challenge      -> Fight boss
/createguild    -> Create or view guilds
/shop           -> Show shop or buy item
/aura           -> Show aura
/setaura <name> -> Set aura
